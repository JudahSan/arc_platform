## Reporting a Vulnerability

The Africa Ruby Community (ARC) team takes the security of our platform and community seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us responsibly.

### How to Report

- **Do NOT** report security vulnerabilities through public GitHub issues, discussions, or pull requests.
- Please report security vulnerabilities via GitHub's private vulnerability reporting feature on this repository, or by emailing the project maintainers directly.
- Include a detailed description of the vulnerability, steps to reproduce, proof of concept (if applicable), and potential impact.

### What to Expect

- **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment:** We will assess the report and confirm the vulnerability.
- **Fix & Disclosure:** We will work on a fix in a private branch/security advisory and release a patch as quickly as possible. We will coordinate public disclosure with you once the vulnerability is addressed.

Thank you for helping keep the Africa Ruby Community safe!
